How Scores Work

Combined Score range: 0 to 3 per hex.

+1 if at least one grocery is within 800m.

+1 if at least one park is within 800m.

+1 if at least one library is within 1200m.

Why Hexes Help

Hexes make coverage easier to compare across neighborhoods.

They smooth noisy point data into a consistent map pattern.

This reduces visual clutter while still showing local differences.

🦆 DuckDB in This Project

DuckDB Spatial was used to count nearby amenities for each hex centroid.

It computes grocery and park counts within 800 meters, and library counts within 1200 meters.

Those counts are then combined into the final Combined Score shown on the map.
